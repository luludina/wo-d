# TabBar icon attribution

The TabBar icons are adapted from the **Ant Design 图标库** collection on Alibaba Iconfont.

- Collection: https://www.iconfont.cn/collections/detail?cid=53964
- Upstream: https://github.com/ant-design/ant-design-icons
- License: MIT
- Icon IDs: `home` 47429091, `calendar` 47428705, `appstore` 47427527, `user` 47429697
- Added icon: Ant Design `trophy` (outlined and filled), distributed through the same Alibaba Iconfont collection

Only the fill color was changed to match the mini program's default and selected states.
