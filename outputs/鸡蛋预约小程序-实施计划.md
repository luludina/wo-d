# 鸡蛋预约小程序实施计划

更新时间：2026-09-28

## 阶段 1：工程基线（已完成）

交付内容：

- pnpm workspace 单仓库；
- Fastify API 基础服务；
- MongoDB 单节点副本集本地环境；
- `/health/live` 与 `/health/ready`；
- 微信原生小程序 TypeScript 骨架；
- 共享协议包和基础质量检查。

完成标准：依赖安装成功，类型检查和基础测试通过，API 可启动，小程序工程可导入微信开发者工具。

完成记录（2026-09-24）：依赖安装、类型检查、构建和基础测试通过；MongoDB 单节点副本集在本地 `27018` 端口成为 `PRIMARY`；API 的存活、就绪与 OpenAPI 页面均返回 200。

- 首位管理员初始化脚本；
- 管理员任命和最后一名管理员保护。

完成标准：注册用户可完成从首次登录到管理员审核通过的完整流程，停用用户无法访问业务接口。
